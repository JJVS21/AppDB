📌 Módulo II – Famosos

      
Obtiene imágenes (thumbnails) de personas famosas a partir de su nombre. Se consulta primero en español; si no hay resultado, se cae al inglés.

    


    

      

        REST API
        Wikipedia API — EN
      

      
en.wikipedia.org/w/api.php

      
📌 Módulo II – Famosos

      
Fallback en inglés para búsqueda de imágenes cuando la versión en español no retorna resultado. Usa el mismo endpoint pageimages.

    


    

      

        REST API
        Nominatim / OpenStreetMap
      

      
nominatim.openstreetmap.org/search

      
📍 Módulo III – Lugares

      
Geocodifica nombres de lugares (obtiene latitud y longitud). Respeta el rate-limit de 1 req/seg. Los resultados se cachean en localStorage.

    


    

      

        Librería JS
        Leaflet 1.9.4
      

      
cdnjs.cloudflare.com · leaflet/1.9.4

      
📍 Módulo III – Mapa mundial

      
Biblioteca de mapas interactivos usada para renderizar el mapa mundial con marcadores por cada lugar geocodificado. Cargada desde CDN.

    


    

      

        Fuente web
        Google Fonts
      

      
fonts.googleapis.com

      
🎨 Global – Tipografía

      
Provee las fuentes IBM Plex Mono (pesos 300, 400, 600, 700) y Syne (400, 700, 800) usadas en toda la interfaz.
